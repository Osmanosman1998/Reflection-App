# My Shift Reflection app (build 1.4)

Phone app for Project SEARCH interns to reflect after each shift. It saves into the Shift Reflection Tracker workbook through Power Automate.

| File | What it is |
|---|---|
| `index.html`, `style.css`, `app.js` | The app. Do not edit. |
| `config.js` | The two Power Automate links go here. This is the only file to edit. |
| `cards.html` | Prints personal QR cards for interns. |

No intern names, targets or answers are stored here. They all live in the Excel workbook.

Full set-up steps are in the **Set-up guide**.
